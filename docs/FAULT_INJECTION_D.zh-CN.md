# 阶段 D 故障注入

基准 9b2ae26，仅修改测试与文档。strict xfail 是未修复缺陷，不是验收通过。

- 游标写入事务中断：源事件、缺口告警和游标整体回滚，重试成功。
- 投递数据库异常：监督器失败退出，而不是静默丢失 Worker。
- 远端 ACK 后本地保存失败：重开数据库，以同一请求 ID 重放，至少一次语义。
- D-M01：非字符串 ACK status 不应导致 Worker 退出（strict xfail）。
- D-M02：优先级调度不能颠倒同故障因果顺序（strict xfail）。

不访问真实打印机或外部 Webhook。同步 SQLite 共享阻塞、永久失败队列仍需专项设计。生产方队列有限，游标不能找回已淘汰数据。
